# Security

Do not put keys, broker sessions, database exports or personal notes in issues, commits or screenshots.

Production identity comes from a trusted Sites gateway. Never deploy directly behind caller-controlled identity headers. Other hosts need a verified session adapter and protected ingress. Development mock authentication is for loopback only.

Writes enforce ownership, origin, content type, shape, size and revision. This is not a complete security audit. There is no financial execution path.

Use GitHub private vulnerability reporting if enabled; otherwise contact the owner privately. Do not disclose exploitable user data in a public issue.
