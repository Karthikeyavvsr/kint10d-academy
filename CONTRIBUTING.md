# Contributing

1. Describe the learning or engineering problem without private data.
2. Keep explanations original and cite primary sources.
3. Preserve lesson IDs; append migrations rather than rewrite applied history.
4. Run type checking, content checks, builds and relevant browser checks.
5. Include screenshots for UI changes and explain test limits.
6. Never commit runtime databases, credentials, notes or personal deployment identities.

AI-assisted contributions are welcome; contributors remain responsible for correctness and attribution.
